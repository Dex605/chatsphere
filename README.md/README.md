# 🌐 ChatSphere

**ChatSphere** is a global messaging web app that connects you with real people from the USA, UK, France, Spain, and Germany.

## Features

- **Sign Up** with username, email, phone number, and password
- **Choose Your Plan** — pick a country to chat with
- **M-Pesa Payment** — pay via M-Pesa to activate your account
- **Browse Members** — view women and men from your chosen country
- **Live Chat** — open a chat with any member

## Running Locally

Just open `index.html` in any browser — no server needed.

## Deploying to GitHub Pages

1. Push to GitHub (see setup instructions)
2. Go to **Settings → Pages**
3. Set source to `main` branch, root folder
4. Your site will be live at `https://yourusername.github.io/chatsphere`
